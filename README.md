# UA Day Site

Niewielka statyczna strona o kuchni ukraińskiej, stworzona z okazji Dnia Ukrainy. Język strony: polski (*Jedzenia* — „Potrawy”).

## Co jest na stronie

- **Strona główna** (`index.html`) — siatka 11 kart z potrawami: Deruny, Pierogi, Barszcz, Naleśniki, Napoleon, Kanapki z słoniną, Szuba, Kwas, Muffiny, Mimoza, Watruszki.
- **Strona potrawy** (`1.deruny.html`, `2.pierogi.html` itd.) — zdjęcie, składniki (*Składniki*) i ciekawostki (*Ciekawostki*). Przycisk *Jedzenia ←* w rogu wraca do strony głównej.

## Technologie

Czysty HTML i CSS, bez budowania i zależności. Czcionka Montserrat jest ładowana z Google Fonts.

## Struktura

```
index.html          strona główna
N.nazwa.html        strony potraw
styles.css          style strony głównej
cardstyles.css      style stron potraw
img/                zdjęcia potraw i tło (Loon.jpg)
```

## Uruchomienie

Otwórz `index.html` w przeglądarce. Serwer nie jest potrzebny.
